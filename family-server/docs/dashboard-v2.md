# 家庭用量面板 v2 规格（待确认）

目标：让网页面板和 Kanjo 本机 app 一样，能按时间段切换、看排行和分析，而不是现在这样只有固定的「本周期」加一长串成员卡片。

## 一、现在的问题

1. 时间段写死：成员卡只显示本周期和上周期，趋势图固定 30 天，没法看今天、本周、上周、重置以来或全部。
2. 七个成员七张大卡，没上报的成员也占一整张，真正想比较「谁用得多」得来回滚动。
3. 没有全家维度的分析：总量、环比、日均、峰值日、按模型和按代理的合计都没有。
4. 模型明细只给每人前 5 个，看不到全家合计的模型排行。

## 二、数据能支持什么（不改上报格式）

每台电脑上报的 `summary` 里有：

| 数据 | 范围 | 每个时间段含有 |
|---|---|---|
| `days` | 最近 62 天 | token 分项、金额、按代理、按服务商（每家前 5 个模型）、前 8 个模型、用过的全部模型名 |
| `weeks` | 最近 26 周 | 同上 |
| `months` | 全部月份 | 同上 |
| `all_time` | 全部 | 同上 |

另外有 `quota_windows`（周额度已用百分比、5 小时窗口、重置时间）和 `plans`。

所以：

- 62 天以内的任意时间段都能按天精确合计。
- 更早的时间只能按周或按月看。
- 每个时间段的模型排行由每天的前 8 个模型加总而成。小模型可能落在前 8 以外，这部分合并显示为「其他」，不会算错总数。

## 三、时间段

顶部一排切换按钮，和 Mac app 一致，另外加「本周」：

**今天 · 本周 · 上周 · 7 天 · 30 天 · 重置以来 · 周期 · 全部**

- 本周和上周都从周一开始，按服务器设置的时区计算。
- 重置以来从 Google AI Ultra 周额度上次重置的那一天算起。数据只到天，所以重置当天整天都算进去，页面上会注明「按天近似」。
- 周期按设置页里的计费日计算。
- 全部用 `all_time`，趋势图改按月显示。
- 默认打开「本周」。切换不刷新页面，所选时间段写进网址（`?range=last_week`），方便收藏。

每个时间段旁边自动对比「上一个同样长度的时间段」：本周对上周，今天对昨天，30 天对再往前 30 天。全部没有对比。

## 四、页面结构（从上到下）

### 1. 总览数字（一行 4–5 个）

总 token（下面一行写折算金额）、和上一时段相比 ±%、活跃成员 N/7、日均 token、峰值日（日期和用量）。

### 2. 额度池卡（保留，压缩成一张）

- 周额度已用 %、剩余、5 小时窗口和重置倒计时，进度条用真颜色。
- 「重置以来谁用掉了额度池」改成一根分段的横条，按人分色，悬停显示数值。
- 多台电脑报的额度不一致时，只显示一行小字提示，点开才看到各台的数值，不再默认铺开。

### 3. 趋势图

- 所选时间段内每天一根柱子，按人堆叠分色。「全部」时每月一根。
- 右上角切换「按人 / 按模型 / 按代理」。
- 悬停显示当天合计和每人的数值。

### 4. 成员排行表（替代现在的七张大卡）

每人一行：

- 颜色点和名字
- token
- 金额
- 占全家百分比的横条
- 和上一时段相比 ±%
- 用得最多的模型
- 最后上报时间
- 状态（正常 / 超过 2 小时未上报 / 从未上报）

规则：

- 按 token 从多到少排序；点表头可以换排序方式。
- 所选时间段内用量为 0 的成员收进底部一行「另有 N 人无用量」。
- 点一行展开：这个人在该时间段的模型明细（全部模型，不只前 5）、每台电脑分别的用量、一条迷你每日柱。

### 5. 分析

- **模型排行**：全家合计每个模型的 token、金额、占比横条和使用人数。
- **按服务商、按代理**：两组小环形图或横条。
- **洞察小卡**，只显示能算出来的，算不出的不显示：
  - 缓存命中率：缓存读取 ÷（输入 + 缓存读取）
  - 输出占比
  - 最贵的模型
  - 用量最多的一天
  - 本周用量最多的人和他的占比
  - 按当前速度，到额度重置时预计用到百分之几（只在「重置以来」和「本周」显示）

### 6. 热力日历

最近 62 天每天一个格子，按全家用量深浅显示，悬停看数值。这是面板自己的记忆点，和 app 的热力条呼应。

## 五、视觉

- 跟随系统浅色/深色。深色用和 app 一样的实心深色面板，不用半透明。
- 每个成员固定一个饱和度足够的颜色，图表、表格、横条全部统一用这个颜色。不用灰扑扑的低饱和色块。
- 手机宽度下排行表改成两行布局，图表可以横向滑动，整个页面不出现横向滚动。
- 不引入外部脚本库，保持现有的 CSP 安全策略。图表继续用服务器生成的 SVG，配少量内联脚本切换时间段。

## 六、实现方式

- **服务端（Python）**：新增一个按时间段聚合的模块。合并每个成员所有电脑的最新上报，算出每个时间段的总数、每人数据、每天数据、模型/服务商/代理合计和对比值，以 JSON 嵌入页面。页面在浏览器里切换时间段，不再请求服务器。
- **不变的部分**：上报格式、数据库、登录、设置页都不改，Mac/Windows 客户端也不用更新。
- **测试**：
  - 每个时间段的边界（周一、跨月、跨夏令时、重置当天）。
  - 多台电脑相加。
  - 无数据的成员。
  - 「其他」模型的合计等于总数。
  - 渲染冒烟测试，并用真实数据的副本截图检查。
- **完成后**：合并到 main，部署到 usage.paytonpei.top，截图给你看。
